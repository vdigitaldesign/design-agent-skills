# Security reporting

Do not publish credentials, private product material or suspected vulnerabilities in an ordinary issue. Use this repository's [private vulnerability report](https://github.com/vdigitaldesign/design-agent-skills/security/advisories/new).

Include the affected release, client, installation route and a minimal redacted reproduction. DAS instructions do not provide a runtime security boundary; review your client's permissions and the tools/files a task can access.
