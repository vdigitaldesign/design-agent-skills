# Skill catalog

Start with `design-router` when you want the agent to work through the task. Choose a specialist directly when the work is already clear. The skills share context and references; each can be installed separately or together.

## Understand the task

| Skill | Use it to | Typical result |
| --- | --- | --- |
| [`design-router`](../skills/design-router/SKILL.md) | Choose and continue the right workflow | The requested design result, or a concrete decision needed to continue |
| [`frame-design-task`](../skills/frame-design-task/SKILL.md) | Clarify the goal, scope, constraints, and decisions | A focused task frame |
| [`reconstruct-design-context`](../skills/reconstruct-design-context/SKILL.md) | Recover product facts from existing sources | A design read with facts and open questions |

## Review what exists

| Skill | Use it to | Typical result |
| --- | --- | --- |
| [`audit-design-surface`](../skills/audit-design-surface/SKILL.md) | Inspect usability, content, layout, states, and accessibility | Findings grounded in the interface |
| [`audit-design-system`](../skills/audit-design-system/SKILL.md) | Understand a system's coverage, consistency, and gaps | A system assessment and recommended approach |
| [`assess-design-reuse`](../skills/assess-design-reuse/SKILL.md) | Compare existing patterns with custom work | A reuse, adaptation, or custom recommendation |

## Create and explore

| Skill | Use it to | Typical result |
| --- | --- | --- |
| [`explore-design-directions`](../skills/explore-design-directions/SKILL.md) | Compare meaningfully different solutions | Alternatives with trade-offs and a recommendation |
| [`develop-visual-direction`](../skills/develop-visual-direction/SKILL.md) | Develop hierarchy, composition, type, color, imagery, and motion | A visual direction and its working rules |
| [`prototype-design-directions`](../skills/prototype-design-directions/SKILL.md) | Make a design choice tangible | A prototype, mock, wireframe, or design lab |

## Carry decisions forward

| Skill | Use it to | Typical result |
| --- | --- | --- |
| [`record-design-decision`](../skills/record-design-decision/SKILL.md) | Preserve a person's explicit choice and its scope | A decision record |
| [`evolve-design-system`](../skills/evolve-design-system/SKILL.md) | Prepare a focused system change | A proposal for tokens, components, patterns, or documentation |
| [`publish-design-system-canon`](../skills/publish-design-system-canon/SKILL.md) | Publish an approved system revision to its designated destination | The approved revision and publication record |

## Deliver and check

| Skill | Use it to | Typical result |
| --- | --- | --- |
| [`write-design-contract`](../skills/write-design-contract/SKILL.md) | Specify the chosen design for a coding agent | Behavior, states, requirements, and implementation handoff |
| [`validate-design-contract`](../skills/validate-design-contract/SKILL.md) | Find gaps or contradictions before implementation | A contract check |
| [`verify-design-implementation`](../skills/verify-design-implementation/SKILL.md) | Compare the built interface with approved requirements | Observed matches, differences, and unchecked behavior |
| [`maintain-design-knowledge`](../skills/maintain-design-knowledge/SKILL.md) | Keep useful decisions and patterns findable and current | A knowledge query or index update |

These are capabilities, not a mandatory sequence or a document checklist. Use the work the task needs. The individual skill files define the workflow; the [shared references](../skills/design-router/references/product-profile-and-tools.md) connect it to your project and tools.
