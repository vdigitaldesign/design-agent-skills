# DAS 0.1.3

The README and plugin use the new green DAS artwork. The package also includes the updated repository social-preview image.

## What changed

This patch replaces the README banner, plugin icon, and social-preview image. The plugin colors and README tagline now match the artwork: "Design work for agents. Authority for humans."

All skill instructions are unchanged from 0.1.2. Package version is `0.1.3`; `TARGET.json` retains instruction target `codex-0.1.2` and its source digest.

## Install or upgrade

Use the [installation guide](../INSTALL.md) for the Codex plugin or project-local skills. The plugin command and fixed-release alternative select `v0.1.3`; the short interactive command follows the repository's default branch. Release assets are `design-agent-skills-0.1.3.zip` and `design-agent-skills-0.1.3.sha256`.

Existing users should follow [replacement instructions](advanced-installation.md#replace-an-earlier-installation), especially when another agent uses the same project folders. The immutable [0.1.2 release](https://github.com/vdigitaldesign/design-agent-skills/releases/tag/v0.1.2) remains available for recovery. Actual publication and verification results for this patch belong to its [GitHub release record](https://github.com/vdigitaldesign/design-agent-skills/releases/tag/v0.1.3).

## Verification scope

The release checks cover artwork rendering, package integrity, unchanged instruction sources, complete resource copies, local links, and a byte-identical archive rebuild using the public maintenance tools.

No new model task was run for this artwork patch. The recorded BorrowDesk, Fieldnote and team-invitation results belong to the earlier RC1 instruction sources used in 0.1.0 and 0.1.1. The [evidence summary](advanced-installation.md#support-and-evidence) preserves those results and their limits.

Version 0.1.3 supports the documented Codex routes. Claude support remains under development and outside this release's supported configurations. Available tools, authentication and model access come from the user's environment.
