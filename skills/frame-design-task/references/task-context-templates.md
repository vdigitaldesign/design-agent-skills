### Claims

For each material claim, record:

- claim;
- class: fact / inference / unknown / conflict;
- source and revision or evidence locator;
- source authority;
- confidence and reason;
- consequence for the design task.

### Protected boundaries

List terminology, routes, fields, permissions, content, identity, or other decisions that available authority does not permit the agent to change silently.

### Material decisions requiring authority

For each decision, state the evidence already gathered, viable options, current recommendation if supportable, trade-offs, and the smallest owner question.

### Safe next work

List research, audit, reuse assessment, or specification preparation that can proceed without resolving the remaining questions.

## Short examples

**Routine conformance:** An effective component contract requires the medium button’s horizontal padding, and the observed implementation differs. Cite the contract and evidence. State that no new interaction or product meaning is introduced, then route to implementation correction and parity review.

**Insufficient context:** “Simplify settings” has no reliable goal, routes, fields, current evidence, or authority. Inspect the available sources and record what is known. Ask for the irreducible product inputs. Abstain before you invent an aesthetic direction or contract.
