# Support

This edition is for Claude Code, through the native plugin or project-local Skills CLI route. Desktop and Cowork behavior are outside its support scope.

Volodymyr Onishchenko (`vdigitaldesign`) maintains DAS. Report ordinary problems and feature requests through a [GitHub issue](https://github.com/vdigitaldesign/design-agent-skills/issues/new). There is no guaranteed response time.

Check [installation](INSTALL.md), the [Claude Code guide](docs/claude-code.md), and [troubleshooting](docs/advanced-installation.md#troubleshooting) first. Include the DAS and client versions, installation route, invoked skill, exact error or missed requirement, and model/settings when known. Describe what you expected and the smallest safe reproduction.

Claude outputs have omitted required behavior and confused review readiness with approval. Review contracts against their governing sources before implementation. Model behavior varies with the task, sources, tools, and settings; this edition does not promise correctness for every workflow.

Remove credentials, customer information, and private product material before posting. Suspected vulnerabilities belong in the [private security reporting route](SECURITY.md). Claude authentication, model access, and third-party integrations remain with their corresponding providers.
