# Changelog

## 0.1.6

This client package is distributed from the shared repository tree with explicit installation paths and a common release version. Its instruction resources and existing artwork are unchanged.

## 0.1.0

First public Claude Code edition of Design Agent Skills, with sixteen skills for design investigation, audits, exploration, decisions, contracts, and implementation checks.

The native plugin and project-local Skills CLI routes select the Claude distribution. The package includes the DAS icon, README artwork, source integrity checks, and self-contained maintenance tools.

Contract completeness and approval boundaries need careful review on Claude. Before implementation, compare the handoff with its governing sources and actual decisions. Desktop and Cowork behavior are outside this edition's support scope.
