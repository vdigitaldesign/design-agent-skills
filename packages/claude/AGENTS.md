# Contributing with an agent

These instructions apply to maintaining this DAS checkout. Installed skills use their own `SKILL.md` and supporting resources. Keep repository contributor guidance outside individual skill folders.

Read [CONTRIBUTING](CONTRIBUTING.md) for source ownership and checks, and [INSTALL](INSTALL.md) before changing installation behavior.

- Tie the change to a concrete user task and useful result. Preserve unrelated work.
- Edit owning sources and regenerate supporting copies. Preserve the target's source-integrity boundary.
- Write clear US English for the person installing or using DAS. Use UX Writing and Humanizer when available; preserve every supported fact, condition, command, and limitation. These writing tools are contributor capabilities, not dependencies of installed DAS skills.
- Keep public copy and metadata free of private development history, local paths, credentials, and customer material. Explain known limitations through their effect on the user's work.
- Run the applicable checks and state their limits. Keep raw model outputs and evaluation criteria unchanged.
- Remove task-created disposable scratch and retain useful evidence. Building a package does not authorize publishing it.
